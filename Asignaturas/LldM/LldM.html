Unidad 1

La unidad 1 de HTML Basica introduce los fundamentos esenciales del lenguaje de marcas para la creación de páginas web. A lo largo del contenido se abordan la estructura básica de un documento HTML, el uso de etiquetas para títulos, párrafos y formatos de texto, y el anidamiento de elementos junto con el uso de atributos. Además, enseña a estructurar la información mediante listas, tablas y comentarios, así como a enriquecer la navegación mediante el uso de enlaces e imágenes.
